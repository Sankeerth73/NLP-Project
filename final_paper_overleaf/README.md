# Final Paper Overleaf Skeleton

Use this folder as the editable Overleaf version of the 8-page ACL-style final paper.

## Recommended Overleaf Setup

1. In Overleaf, create a new project from the official ACL template, or upload the ACL style files:
   - `acl.sty`
   - `acl_natbib.bst`
2. Replace the template's `main.tex` with this folder's `main.tex`.
3. Replace or add `references.bib`.
4. Set compiler to pdfLaTeX.
5. Keep `\usepackage[review]{acl}` while drafting if the instructor wants review style with line numbers. For final camera-ready style, change it to `\usepackage{acl}`.

## Member Editing Map

- Member A: Sections 2 and 4.
- Member B: Section 5.
- Member C: Sections 6 and 7.
- Member D: Abstract, Sections 1, 3, 8, Limitations, references, and final integration.

## Page Target

The main paper should fit in 8 ACL pages, excluding references and appendices. Keep the main text self-contained: do not move core results only to the appendix.
